# 六、屏与档之间的切换（决策 4）

> 这一节属于 [`../P0.md`](../P0.md)（骨架 · 总体规划）。上一节 [`05-side.md`](./05-side.md) · 下一节 [`07-rules.md`](./07-rules.md)

| 我现在在哪 | 按什么 | 到哪 | 我站在哪条线 | 回来时 |
|---|---|---|---|---|
| 任何档 | 那个键 | ① → ② → ③ → ①（跳过不存在的档） | 不变 | 内容区换掉；壳与侧边不动。从档 ① 进档 ② 时**默认盯住我站着的这条线**；从档 ③ 退下来时盯住我在树上选的那条 |
| 档 ③ | `↑↓` | 在树上移选中（同时就是「盯哪一条」；**相机跟着滚**） | 不变（只是选中） | —— |
| 档 ② | `↑↓` | 换盯的那一条（**同一个选中**；树段窗口跟着滚） | 不变（只是盯） | —— |
| 档 ② | `enter` | 档 ①，内容是我盯的那一条 | **变**（切到它） | 同「切节点」，不写账 |
| 档 ③ | `enter` | 档 ①，内容是选中的那条线 | **变**（切到它） | 切节点**不写账** |
| 档 ③ / ② | `esc` | 档 ② / 档 ① | 不变 | 收掉那一层：整棵树 → 落回一小段；树段 → 回对话 |
| 档 ① | `esc` | 档 ① | 不变 | 什么都不做（人不能收回某一手；停整条线是 [§一](01-stories.md) 故事 20 的 `ctrl+x`） |
| 任何档 | `ctrl+b` / `alt+b` | 档 ①，内容是**新线** | **变**（站到新线上） | 在树上分叉时，新线挂在选中行下面 |
| 任何档 | 侧边那个键 | 侧边三态循环 | 不变 | 内容区宽度变 |
| 任何档 | 进屏（[§二](./02-screens.md) 那三条路：修饰键 / `/` 命令 / 从正文点进去） | 那一屏 → `esc` 回来 | 不变 | 回来时是**原档、原侧边态** |

**两条纪律**：① 一个键在不同地方可以不同含义，但在同一处只有一个含义，**且界面上写得出**（底下那行右端 + 状态行当场写）。② **面板不许吞普通打字**：在树上、在侧边开着时，打字照旧进输入行；名单类屏里打字是**过滤名单**。
