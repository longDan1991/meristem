# 九、还没定

> 这一节属于 [`../P0.md`](../P0.md)（骨架 · 总体规划）。上一节 [`08-handoff.md`](./08-handoff.md) · **最后一节**

1. **侧边里那三页"数据从哪来"**：待办 / 目标 / 名册这三页照抄了 jcode 的位置，但**它们背后要有对象**（`todo` / `goal` / 多 agent）—— 我们的设计里现在没有，而 [§七](./07-rules.md) 的产品级不做清单里也反对过它们。**是"先把位置与页面留着、对象以后再说"，还是"连对象一起照抄进来"** —— 这一条要你定，我不再自己判。
2. **正文字里的材料怎么进侧边**：从正文里点一个文件名就开侧边（两家的做法），还是走一个键（照抄 jcode 的键）？
3. **侧边宽度**给几档（jcode 是 `Ctrl+1..4` 四档）。
4. **档 ② 里我说的话进哪儿**：倾向于"照常进这条线、那段窗口不自动收起"。
5. **选中 / 复制**：是"一整屏"还是"一个模式"（jcode 是一个模式，在三个区里各自选块）。
6. **在对话里搜**：搜什么（我说的话 / 它说的话 / 手的交代）+ 怎么跳（跳到那一段）。
7. **`esc` 在档 ① 的第二种情形**：没有在跑作业时它什么都不做 —— 要不要改成"收掉正文里折起来的东西"。
8. **退出前要不要一句确认**（现在定的是不问）。
9. **几个键还没起名**：档位循环那个键、侧边三态那个键与内容轮换那个键、挑角色那个键、诊断那条命令的名字。**已经定的（照抄两家）**：挑模型 `alt+m`、选中 / 复制 `alt+y`、对话内搜索 `ctrl+r`、键位表 `/help`、变更日志 `/changelog`、正文卡片展开 `ctrl+o`。起名时要**比着整张键表**看，避免撞车。
