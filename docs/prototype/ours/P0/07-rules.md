# 七、全局规则（跨档、跨屏）

> 这一节属于 [`../P0.md`](../P0.md)（骨架 · 总体规划）。上一节 [`06-switching.md`](./06-switching.md) · 下一节 [`08-handoff.md`](./08-handoff.md)

1. **画布**：120×40 / 80×24；双宽按显示宽度算列；行末不留半格（否则整块串位）。
2. **键的归属**：输入框只吃"正文 + 光标移动"（可打印字符、退格、左右、行首行尾）；其余键**先给界面**。`↑↓` 归内容区的档 ③（整棵树）—— **前提是草稿只有一行**（多行草稿留给后面那份，到时候这条要重新想）。
3. **说不出来的限制才是惩罚**：截断 / 折叠 / 视野外还有多少都要看得见（`…` / `▸ N` / `↑N`），并且给出取回的办法。
4. **不骗人**：屏幕上要么是账里的事实，要么明说是**失败**或**待发**。入账的每一句都来自账、或来自作业自己说的话 —— **界面不生成文本**。
5. **不重写历史**：账 append-only。过期的东西归档、不删；**要收敛就分叉**。
6. **零计数器**：节点数 / 深度 / token / 时间 / 并发都不设上限；"放不下先丢谁"是**显示**的取舍，不是配额（作业的超时不是配额，它归那只手自己）。
7. **同一件事只有一个出口**：名字只在事实行左端与树行上；用量只在事实行右端；能用的键只在**眼前这一层**的键行（每屏自带一条，不是全屏共用一条）；"在跑几个"只由"谁在动"那条与状态行说。
8. **没有撤销**：账不可改写 —— 做错了就接着说一句、或分叉出一条新的。界面上**不许**出现"撤销"这类假动作。
9. **产品级不做**：

| 不做 | 一层理由 |
|---|---|
| 打断正在生成的模型回复 | 我能做的三件事是**取消作业 / 重试 / 接着说**（§9.5） |
| 手动压缩上下文 | 账不另存、不重写；**上下文满了的收敛动作是分叉**（尤其总结分叉） |
| 清屏 / 清上下文 / 删除一条线 | 视图就是账；账只追加（§5.8）。要"干净的一段"就分叉 |
| 撤销 | 同上：账不可改写 |
| 逐手开关 / 工具清单界面 | 手由**角色**点名（§4）；另立一处开关会让同一件事有两份定义 |
| 主题 / 动画 / 显示开关 | 不加旋钮（§5.5） |
| 审批 / 协作 / 账号 / 插件市场 | 各自在 [`../overview.md`](../../overview.md) §三 里有优先级与理由 |
