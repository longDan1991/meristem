# 三、全局布局：壳 + 内容区 + 侧边

> 这一节属于 [`../P0.md`](../P0.md)（骨架 · 总体规划）。上一节 [`02-screens.md`](./02-screens.md) · 下一节 [`04-tiers.md`](./04-tiers.md)

```text
┌ 内容区（占掉剩下的行）                             ┬ 侧边（三态）     ┐
│ 三档里的一档（见 §四）：                           │ 收起 = 0 列      │
│   ① 这段对话（默认）                               │ 分栏 = 右侧一列  │
│   ② 盯住一条 = 树的一小段                          │ 全屏 = 占满内容区│
│      + 选中那行的实况                              │                  │
│   ③ 整棵树                                         │                  │
└────────────────────────────────────────────────────┴──────────────────┘
```

**壳 = ③ 状态行 + ④ 输入行 + ⑤ 底下那行。** 这三条**任何档、任何屏都在原位、一格不动**。理由（支撑前面二十一条故事）：

1. **"我在哪条线 + 用哪个脑子 + 烧了多少"永远看得见**（⑤ 属于壳）。哪怕我在树上翻、在侧边看文件、在搜一句话，我都知道自己站在哪。
2. **"我怎么说话"永远不动**（④ 属于壳，位置固定）；看别的档时手还在它上面（`面板不许吞普通打字`）。
3. **只有"看的东西"会换**：内容区（三档）+ 侧边（三态）。不搞"把某块挤一挤"这种局部变化，所以换档 / 开侧边都不会让任何东西重新排版。
4. **画布**：主设计 **120×40**，最低保证 **80×24** 不崩不乱码；中文按显示宽度算列；**任何一行末尾不许留半格**。

**两块可变区的细节各自在哪**：**内容区**（那三档：各自看什么、怎么循环、`esc` 收掉什么）→ [§四](./04-tiers.md)；**侧边**（三态怎么轮、里面能放哪些页、数据从哪来）→ [§五](./05-side.md)。这一节只管它们**在整屏里各占哪一块、谁不动**。

**"谁在动"那条（一行一段对话：在跑几个 / 出错了）不属于壳 —— 它属于档 ①。** 它**只在档 ① 画**：档 ② 那个位置让给**树的一小段**（不重复画一份平行的名单，见 [§四](./04-tiers.md)），档 ③ 也不画 —— 同一件事不在两处说。它长在**内容区底部、状态行正上方**（两家都放这儿：jcode 的 swarm 条、omp 的 Subagents 块都在输入区上方那一带），一行一条、最多 3 行 + 1 行"还有 N 条"，**没有活就整条不出现**。
