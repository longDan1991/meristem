# 三、全局布局：各屏自带的几行 + 内容区 + 侧边

> 这一节属于 [`../P0.md`](../P0.md)（骨架 · 总体规划）。上一节 [`02-screens.md`](./02-screens.md) · 下一节 [`04-tiers.md`](./04-tiers.md)

```text
┌ ① 内容区（占掉剩下的行）                           ┬ ② 侧边（三态）   ┐
│ 三档里的一档（见 §四）：                           │ 收起 = 0 列      │
│   这段对话（默认）                                 │ 分栏 = 右侧一列  │
│   盯住一条 = 树的一小段 + 选中那行的实况            │ 全屏 = 占满内容区│
│   整棵树                                           │                  │
└────────────────────────────────────────────────────┴──────────────────┘
③ 状态行   眼前这一件正在发生的事 + 上一动作的回执          ┃ 主屏自带
④ 输入行   我怎么说话（打字 + 敲 `/` 弹出的命令名单）        ┃ 主屏自带
⑤ 事实行   名字 · 角色 · 目录 ｜ 用掉多少                   ┃ 主屏自带
⑥ 键行     这会儿能按什么                                  ┃ 每一屏自带
```

**谁画哪一行，只看一件事：这一行写的东西跟着谁走。**

| 块 | 写什么 | 跟着谁走 | 谁画 |
|---|---|---|---|
| ③ 状态行 | 眼前这一件正在发生的事（在跑的那一手 / 正在吐字 / 树在休息）+ **上一动作的回执**。**还没有线就不出现** | 我站着的那条线 | 主屏自带 |
| ④ 输入行 | 我怎么说话：打字，以及敲 `/` 弹出来的命令名单 | 我站着的那条线 | 主屏自带 |
| ⑤ 事实行 | 名字 · 角色 · 目录 ｜ 用掉多少。**还没有线也没有回执就不出现** | 我站着的那条线 | 主屏自带 |
| ⑥ 键行 | 这会儿能按什么 | **眼前这一层** | **每一屏自己**（主屏也有一条） |

上面那一整块（**① 内容区 + ② 侧边**）也是主屏的（[§二](./02-screens.md) 2.2：那是"**它里面的**"两块；别的屏既没有侧边，也没有那三档）。**所以壳上什么都不画**：三条跟着"我这条线"走的只有主屏有；键行每一屏都不一样（进屏、回来、退出、走位，各自能按的本来就不是同一批）—— 没有一行是"哪一屏都长一样"的。壳只剩两件事：**给屏留一格**、**接全界面共用的那几条命令**。

**跟着眼前这一层走的那一行（⑥）由这一屏自己画**：它写的就是这一屏现在真能按的键 —— 照抄两家的做法（jcode 的面板、omp 的弹层都把键位行放在那一层自己身上），也只有这样它才说得准"这一层"的键。理由（支撑前面二十一条故事）：

1. **"这会儿能按什么"永远看得见**（⑥ 属于眼前那一层）。站在哪一屏，那一屏最底下都有一行写着能按什么 —— 而且它写的**就是按下去真的会动**的那些（表 + 总线当场问出来，[§七](./07-rules.md) 规则 7）。
2. **"我在哪条线 + 用哪个脑子 + 烧了多少"在主屏上一眼看得见**（③ 与 ⑤ 位置固定）。哪怕我在树上翻、在侧边看文件、在搜一句话，一回到主屏它们就在那儿。
3. **"我怎么说话"在主屏上永远不动**（④ 位置固定）；看别的档、开侧边时手还在它上面（`面板不许吞普通打字`）。
4. **只有"看的东西"会换**：① 内容区（三档）+ ② 侧边（三态）。不搞"把某块挤一挤"这种局部变化，所以换档 / 开侧边都不会让任何东西重新排版。
5. **画布**：主设计 **120×40**，最低保证 **80×24** 不崩不乱码；中文按显示宽度算列；**任何一行末尾不许留半格**。
6. **代价（说清楚）**：主屏自带四行固定开销（③④⑤⑥）—— 进屏时它们跟着会话一起退场，换成那一屏自己的身子与它那一条键行。

**两块可变区的细节各自在哪**：**内容区**（那三档：各自看什么、怎么循环、`esc` 收掉什么）→ [§四](./04-tiers.md)；**侧边**（三态怎么轮、里面能放哪些页、数据从哪来）→ [§五](./05-side.md)。这一节只管它们**在整屏里各占哪一块、谁自带哪一行**。

**"谁在动"那条（一行一段对话：在跑几个 / 出错了）不属于这几行 —— 它属于档 ①。** 它**只在档 ① 画**：档 ② 那个位置让给**树的一小段**（不重复画一份平行的名单，见 [§四](./04-tiers.md)），档 ③ 也不画 —— 同一件事不在两处说。它长在**内容区底部、状态行正上方**（两家都放这儿：jcode 的 swarm 条、omp 的 Subagents 块都在输入区上方那一带），一行一条、最多 3 行 + 1 行"还有 N 条"，**没有活就整条不出现**。
