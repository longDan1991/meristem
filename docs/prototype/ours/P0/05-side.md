# 五、侧边（决策 3；照抄 jcode）

> 这一节属于 [`../P0.md`](../P0.md)（骨架 · 总体规划）。上一节 [`04-tiers.md`](./04-tiers.md) · 下一节 [`06-switching.md`](./06-switching.md)

**右侧一列，三态循环，一个键**：

| 态 | 我看到的 |
|---|---|
| **收起** | 右侧 0 列，正文用满宽度 |
| **分成两栏** | 右侧一列（正文变窄，还在） |
| **占满全屏** | 侧边内容占满内容区，正文暂时让位；壳不动 |

**照抄 jcode 的四件**：① 一个键在三态之间循环；② 一个键在**页面**之间轮换；③ 宽度可调；④ 方向可换（左右 / 上下）。

**侧边里能放什么（照抄 jcode 的页面种类）**：

| 页面 | 我什么时候用它 | 数据从哪来 |
|---|---|---|
| **材料 / 文件全文** | 它提到某个文件，我想看全文；或把一份材料摊在旁边 | 模型提到的文件路径 / 我自己放进去的材料 —— **有** |
| **图与 PDF** | 它给了图 / 我想看某个 PDF | 模型给的图 / 文件 —— **有** |
| **改动（diff）** | 它改了什么，我要一行行看 | 它动过的文件 —— **有** |
| **回望** | 我离开过，回来想知道"刚才发生了什么" | 账 —— **有** |
| **这一手的原文** | 当前这一手吐了什么、吃进去什么（照抄 jcode 的 `observe` 页） | 作业表 + 作业自己吐的原文 —— **有** |
| **待办** | 这条线还剩什么没做 | jcode 这一页背后是"模型有 todo 这个对象"，**我们的设计里没有它** → 见 [§九](./09-open.md) |
| **目标 / 计划** | 看这一轮的目标与步骤 | 同上：**要先有对象** → 见 [§九](./09-open.md) |
| **名册** | 同时有好几只 agent 在跑 | 同上：**要先有"多 agent"这件事** → 见 [§九](./09-open.md)（只做侧边这一页；独立的整屏名册不做，见 [§二](./02-screens.md) 的不做清单） |

**代价（写清楚）**：开了两栏，正文的换行宽度就少一列，**长行会多折几行**；全屏时我看不见对话（壳还在，但正文让位）。
